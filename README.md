# Código Violeta — Web educativa

## Ejecutar
1. Descomprime el ZIP.
2. Abre la carpeta en Visual Studio Code.
3. Abre `index.html` en el navegador o usa Live Server.
4. No requiere Node.js ni instalación de dependencias.

## Estructura
- `index.html`: portada y secciones.
- `css/styles.css`: estilos responsive, fondo violeta y animaciones.
- `js/app.js`: módulos, quiz, plan imprimible, simulador, verificador y progreso.
- `assets/`: imágenes proporcionadas y mascota PNG con fondo transparente.

## Seguridad y límites
El progreso se guarda en el navegador (`localStorage`) y puede ser visible a quien use el mismo perfil. El plan personal solo se procesa localmente al imprimir; no se envía a un servidor. La salida rápida abre Google en otra pestaña pero no borra historial. El SOS automático, GPS en vivo, seguimiento de ruta, backend, estadísticas agregadas y panel administrativo requieren implementación adicional. Verifica siempre los canales oficiales de ayuda antes de publicar la web. Este material no reemplaza atención profesional ni servicios de emergencia.
